# 手写数字识别 · 自定义训练 (MNIST + CNN + Tkinter)

用 PyTorch 训练卷积网络, 再用 Tkinter 图形界面识别鼠标手写的数字。

在原本"画一个数字 → 实时识别"的基础上, 增加了**自定义训练模式**: 自己画样本、
按分区和数据集整理、可视化搭网络、后台训练出自己的 `.pt` 模型、把整个工程打包成
`.ptp`, 并对测试集做批量通过/不通过检验。

```
鼠标笔画 → 画板墨迹(0~1 灰度) → 预处理 → 网络 → softmax → 识别结果 / 匹配度
```

## 环境要求

- Python 3.10+(开发环境为 3.14.6)
- `torch`(有 CUDA 会自动用 GPU, 没有也能用 CPU)
- `numpy`、`Pillow`
- `tkinter`(Windows 官方 Python 安装包自带, 不是 pip 依赖)

```
pip install -r requirements.txt
```

> 从 PyPI 默认装的是 CPU 版 torch。要用 NVIDIA GPU 加速训练, 请到
> <https://pytorch.org/get-started/locally/> 选择对应 CUDA 版本的安装命令。
> Linux 下若缺少 tkinter, 执行 `sudo apt install python3-tk`。

## 快速开始

```
python app.py          # 启动界面
python selftest.py     # 跑一遍纯逻辑自测(不需要窗口, 100 项检查)
```

启动后:

1. 主界面是**识别**: 直接在左上方画板上写 0~9, 右侧立刻给出**识别结果**、
   **置信度**和**匹配度**。识别相关的东西都在这一页, 没有训练按钮。
2. 想训练自己的模型, 点右侧最下面的 **「自定义训练模式」** 按钮 ——
   主界面会被隐藏, 换成自定义训练界面; 点左上角的 **「← 返回主界面」** 回来。
   两边共用同一块画板, 墨迹不会丢。

模型放在**程序目录的 `models/` 里**(默认模型是 `models/mnist_cnn.pt`, 未随仓库
提供)。这个目录下的 `.pt` 启动时会被自动扫描并出现在模型列表里; 文件不在时
程序会弹一个提示框, 但界面照常能用, 你可以进自定义模式自己训一个, 或点
「导入」选一个现成的 `.pt`(会被复制进 `models/`)。

## 自定义训练模式

界面分成两页, **高度一致**(切页时窗口只有宽度变化), 互不干扰:

| | 主界面(识别模式) | 自定义训练模式 |
| --- | --- | --- |
| 位置 | 启动即是 | 点主界面右侧「自定义训练模式」进入, 点「← 返回主界面」退出 |
| 内容 | 画板 + 识别结果 + 置信度 + 匹配度 + 模型选择 | 画板 + 分区与数据集侧边栏 + 参考模型 / 数据集下拉 + 训练/测试/模型参数 + 匹配度 |
| 画板底部 | `清空` | `清空` `删除` `下一张` |
| 离开时 | 不问 | 弹窗问是否保存 |

进入自定义模式时主界面会**整体隐藏**(不是叠一层), 窗口标题也会变成
`自定义训练模式 — 工程名`。两页共用同一块画板的内容, 来回切换不会丢笔。
两页高度一致, 切页时窗口只有宽度变化。

### 识别模式

识别模式就是**随手写数字看一眼**的地方:

- 画板底部只有 `清空` —— **没有「识别」按钮, 也没有「实时识别」开关**:
  一律实时, 边画边出结果。
- **匹配度显示的是模型的完整输出**, 不是"工作区里的数据集"。也就是说即使你
  只建了一个数据集 `a`, 这里也会列出模型全部 10 类(0~9)的概率 —— **按模型
  标签表的顺序(0~9), 不按概率排序**, 所以边写边识别时每一行都待在原地,
  不会跳来跳去; 属于你自己数据集的那些类会额外用 `●` 标出来。
- 进度条按**真实概率**画: 99.2% 是满格, 0.1% 就是几乎看不见的一根细线,
  不会出现"概率为 0 却画成满格"。
- 关窗口时不弹保存提示(这里只是随手试试, 不打扰)。

### 模型选择与记忆

模型全部放在程序目录的 **`models/`** 里, **启动时自动扫描**该目录下所有 `.pt`,
逐个登记进模型列表 —— 自己训练出来的模型丢进 `models/` 就能直接选, 不用每次导入。

两页的右上角都有一个**自绘的模型选择控件**(不是系统下拉框 —— 系统下拉的选中
高亮是纯蓝且盖不满整行, 很碎)。点一下展开卡片列表:

- 悬浮色 `#e0eef9`, 按下色 `#cce4f7`, 覆盖整张卡片(8px 圆角, 卡片间 4px 间隔);
- 当前模型带 ✓ 并高亮;
- **单选**: 点一张就自动取消其它所有卡片的选中态;
- 旁边是「导入」按钮, 可以选择**任意位置**的 `.pt`: 程序先确认能读, 再把它
  **复制进 `models/`** 并切换过去(`models/` 里已有同名文件时会先问一句再覆盖)。
  复制而不是原地引用, 是为了让 `models/` 成为模型的唯一去处, 原来的文件挪走
  或删掉都不影响使用。

默认是 **`mnist数字识别`**(`models/mnist_cnn.pt`, 10 类 0-9)。

**选择会被记住**: 每次切换 / 导入模型都会写进程序目录下的 `settings.json`。
路径**尽量记成相对程序目录的形式**, 这样整个工程换个位置、或者 `models/` 里
的文件移动/改名, 记录依然有效:

```json
{
  "version": 1,
  "model": {"name": "painter_ab", "path": "models/painter_ab.pt"}
}
```

下次启动会自动切回这个模型。如果记的模型文件被删了、或者加载失败、或者
`settings.json` 本身损坏, 都会安静地回落到默认模型, 不会弹错误框。
两页的选择控件共享同一份列表与当前下标, 所以永远一致。

### 三个概念

| 概念 | 说明 |
| --- | --- |
| **分区** | 只有两个: **训练集**(train) 和 **测试集**(test) |
| **数据集** | 名字是**单个字符**, 它同时就是**分类标签**(例如 `a`、`5`、`猫`) |
| **图片** | 画板上画出来的图, **编号由程序自动分配**, 从 0 开始, 每个数据集独立 |

### 自定义模式的侧边栏(三段式)

1. **上: 分区选择框** —— 训练集 / 测试集, 切换后中间立刻显示该分区的数据集。
2. **中: 滚动区** —— 每个数据集一个可折叠块, 展开后列出图片(缩略图 + 编号)。
   **单击或双击**列表项即可打开图片, 不使用标签页。数据集很多时可以滚动。
3. **下: 按钮** —— `新建数据集` `删除数据集`(二次确认) `保存工程(.ptp)` `打开工程(.ptp)`。

`保存工程` 的路径是这么定的: **新工程**问一次存哪儿(默认落在程序目录),
**打开过 / 存过的工程**直接覆盖原来那个文件、不再弹框; 万一那个位置写不进去
(没权限、文件被占用、盘满), 会说明原因并**再让你换一个位置**, 取消则放弃保存。

右侧一栏是 **训练模型** / **测试测试集** / **模型参数**, 下面实时显示当前数据量
是否够训练(例如"训练集 2 类 / 16 张，测试集 4 张。\n当前数据已满足训练条件")。

### 画板区(两页都有)

- 画笔 / 橡皮 / 粗细滑条。
- **识别模式**底部只有 `清空` —— 一律实时识别, 没有开关也不用手点。
- **自定义模式**底部: `清空` / `删除` / `下一张`。
  - `下一张` —— 在**当前打开图片所在的数据集**里新建一张空画板, 并打开它。
  - `删除` —— 删除当前这张图, 会二次确认。**编号不重排**: 删掉 3 号之后
    数据集里就是 0,1,2,4, 下次 `下一张` 会**补上缺的 3 号**。

### 侧边栏里的数据集卡片

每个数据集是一张**自绘卡片**(8px 圆角、悬浮 `#e0eef9`、按下 `#cce4f7`,
覆盖整张卡片)。为了看清画得轻的笔画, 缩略图会**先按最大值归一化**再缩放 ——
否则淡淡的笔画缩到 26px 之后几乎全白, 看着就像没显示。

**一次只展开一个数据集**: 点开另一个, 前一个自动收起, 选中态也只有一处。

缩略图是**实时**的: 在画板上落笔, 侧边栏里对应那一行的缩略图跟着变, 不用重开工程
(只重画那一行, 不重建整个列表, 所以不会闪)。

### 匹配度

右侧的**匹配度滚动列表**两页含义不同, 但**都不排序**, 位置固定:

| | 识别模式 | 自定义训练模式 |
| --- | --- | --- |
| 一行是什么 | 模型输出的**每一个类别** | 工作区里的**每一个数据集** |
| 顺序 | 模型标签表的顺序(0~9) | 数据集名的顺序 |
| 多少行 | 模型有多少类就多少行(与有没有建数据集无关) | 建了多少个数据集就多少行 |
| 额外标记 | 属于自己数据集的类别前面有个 `●` | 模型没覆盖的标签显示"模型未覆盖" |

两页都按**真实概率**画进度条: 99.2% 是满格, 0.1% 就是几乎看不见的一根细线;
当前这一页里概率最高的那一项高亮成绿色。行多了可以滚动查看。

### 训练

1. 进自定义训练模式, 点右侧的 `训练模型`(想先调网络就点 `模型参数`)。
2. 程序先弹出**另存为**对话框让你选 `.pt` 的存放位置(**默认就在 `models/`**,
   取消则不训练); 之后训练对话框里的「保存模型…」也跟着落在同一个目录。
3. 训练在**后台线程**里跑: 界面不卡, 有进度条、逐轮日志, 随时可以**取消**。
4. 训练完成后自动写入该 `.pt`, 并**登记到模型下拉框、切换为当前模型**。
5. 若测试集非空, 每轮都会评估并按最佳通过率保存权重; 否则用末轮权重。

### 测试

点 `测试测试集` 会快速跑一遍**测试集**: 预测结果与图片所在数据集一致就算"通过"。
弹出的小窗口顶部是"通过 X / 不通过 Y", 下面是可滚动的明细:

```
a/图片0  ->  a          ✓ 通过
b/图片1  ->  c          ✗ 不通过(期望 b)
```

双击明细行会在主窗口里打开那张图, 方便定位错例。

### 模型参数(卡片式)

每张卡片代表网络里的一层连接项目:

| 卡片 | 可调参数 |
| --- | --- |
| `Conv` | 通道数、卷积核(1/3/5)、padding(0/1/2)、激活(ReLU/无) |
| `Pool` | 池化窗口(2/3/4) |
| `FC` | 隐藏单元、激活、Dropout |

- `↑` `↓` 调整顺序, `✕` 删除, 底部按钮添加新卡片。
- **输出层不用建卡片**: 程序按类别数(= 数据集个数)自动补一层
  `Linear(→ 类别数)`, 训练用交叉熵损失。
- 顶部可选**输入模式**:
  - `center`(默认) —— 先裁剪外接框, 再 LANCZOS 缩放并**按重心居中**到 28×28,
    与 MNIST 风格一致;
  - `raw` —— 整幅画布直接缩放到 28×28, 不裁剪不居中, 适合 MLP 之类的自定义结构。
- 底部实时显示参数量; 结构不合法(例如把特征图池化成 0)时, 错误会标在**对应的
  卡片下面**, 并且"确定"按钮禁用。
- 「恢复默认」一键回到与 `DigitCNN` 完全等价的架构(输出 10 类时 421,642 个参数)。

## 文件格式

### `.ptp` —— 工程包(本质是 zip)

```
(root)/
├─ train/<数据集单字>/<编号>.pnt      # 训练集
├─ test/<数据集单字>/<编号>.pnt       # 测试集
└─ modelinfo.json
```

`modelinfo.json` 记录:

```json
{
  "format": "ptp", "version": 1,
  "preprocess": {"input_mode": "center", "mean": 0.1307, "std": 0.3081, "canvas": 280},
  "partitions": {"train": {"a": [0, 1]}, "test": {"a": [0], "b": [0]}},
  "class_labels": ["a", "b"],
  "arch": { "input_mode": "center", "num_classes": 2, "cards": [ ... ] },
  "model": {"name": "…", "pt": "…", "labels": ["a", "b"], "accuracy": 0.98},
  "test_config": {"epochs": 12, "batch_size": 32, "lr": 0.001, "augment": true}
}
```

模型权重**不打进 `.ptp`**: 模型统一用 `.pt` 传递, `modelinfo.json` 里只记录
当时用的是哪个模型。

> 打开 `.ptp` 时, 如果包里引用的 `.pt` 还没导入, 程序会提示你用「导入」加载它。

### `.pnt` —— 自制图片格式(保留墨迹深浅)

存的是**保存时刻的画板位图**, 不做 28×28 裁剪/居中 —— 预处理只在训练和推理时
按 `input_mode` 统一执行, 两者绝不会分叉。

```
offset 0   : b"PNT1"            魔数
offset 4   : uint16  版本 = 1
offset 6   : uint32  宽
offset 10  : uint32  高
offset 14  : uint8   输入模式(0=center, 1=raw)
offset 15  : 6 字节保留
offset 21  : 宽 × 高 字节, uint8 灰度, 墨迹深浅 = round(ink × 255)
```

读取端还能回退读取同名 `.png`(自动判断是"黑墨白底"还是"白墨黑底"),
所以早期用 PNG 导出的素材也能直接用。

### `.pt` —— 模型

本程序保存的 `.pt` 是**自描述**的, 里面同时存了架构、标签表、输入模式与归一化
统计量, 因此导入时不需要你再提供任何额外信息:

```python
{"format": "painter-pt", "version": 1, "name": ..., "arch": {...},
 "labels": [...], "input_mode": ..., "mean": ..., "std": ...,
 "accuracy": ..., "state_dict": {...}}
```

也**兼容旧的裸权重文件**(例如 `models/mnist_cnn.pt`): 这种只含
`state_dict` 的文件会按内置 MNIST 结构(10 类)解释, 识别行为与以前一致。

## 识别流程说明

```
鼠标笔画 → 280×280 灰度墨迹图 → 裁剪外接框 → LANCZOS 缩放至 20×20
        → 按重心居中放入 28×28 → (x-0.1307)/0.3081 归一化 → CNN → softmax
```

这一套预处理(尤其是"裁剪 + 按重心居中")是让手写数字对齐 MNIST 训练分布、
从而拿到高准确率的关键。自定义训练模式在 `center` 输入模式下走的是**完全相同**的
预处理, 所以自定义模型和老模型的行为一致。

## 高 DPI 支持

界面在 4K / 高分屏以及 Windows 缩放(125% / 150% / 200% …)下会自动适配:

- **开启进程 DPI 感知**: 在创建窗口前调用
  `SetProcessDpiAwarenessContext(PER_MONITOR_AWARE_V2)`, 失败时依次回退到
  `SetProcessDpiAwareness(2)` 和 `SetProcessDPIAware()`。不开启的话 Windows 会把
  96 DPI 渲染的位图整体拉伸, 界面发虚。
- **按 DPI 等比缩放**: 所有尺寸常量都是 96 DPI 下的"逻辑像素", 运行时经
  `Metrics.px()` 换算成物理像素, 覆盖画板、笔尖、控件内边距、侧边栏、匹配度条
  以及各个对话框。
- **字号同步**: 调用 `tk scaling` 设为 `dpi / 72`, 使点值字号随 DPI 等比放大。
- **跨显示器自适应**: 窗口被拖到不同缩放比的显示器时会重排界面, 并把已有墨迹
  用 LANCZOS 重采样到新尺寸, 不会清空已写内容。状态栏会显示
  `显示缩放: 100% (96 DPI)`。

## 自测

```
python selftest.py
```

覆盖(共 100 项检查, 全部纯逻辑、不需要窗口):

- `.pnt` 往返: 尺寸/模式/量化误差(< 1/255)、深浅信息保留、空图与 1×1 边界、
  坏魔数与长度不符的报错、PNG 退路;
- `.ptp`: zip 目录结构与规定**逐项一致**、modelinfo 字段、内容完全还原、
  缺 `modelinfo.json` / 非 zip / 单个坏图片的处理;
- 架构: 默认卡片序列与 `DigitCNN` 的**参数数量、state_dict 键名与形状完全一致**
  (即老权重可直接装入)、多种非法结构的报错与卡片序号;
- 训练: 合成数据可收敛到 100%、取消不返回权重、单类别/全空白等拒绝路径;
- 全链路: 真实 MNIST 图片 → `.pnt` → `.ptp` → 训练 → `.pt` → 重新加载后预测正确;
- 老的 `mnist_cnn.pt`(现放在 `models/`)兼容加载, 并在真实 MNIST 子集上验证准确率 > 90%。

## 打包成 exe(可选)

```
make app
```

用 PyInstaller 打包 `app.py`。**模型不打包进 exe**, 而是在打包完成后把整个
`models/` 目录复制到安装目录(`dist/Number Scanner/models`), 程序运行时在
**exe 旁边**找它 —— 所以以后想换模型, 直接替换安装目录里的 `models/` 就行,
不用重新打包。(`Number Scanner.spec` 里也做了同样的事, 直接跑
`pyinstaller "Number Scanner.spec"` 也一样。)

新增的模块都在同一目录下, 会随 `--onedir` 一并打包, 不需要额外配置。
程序目录的判定见 `paths.py`: 开发时是源码目录, 冻结后取 exe 所在目录,
`models/` 与 `settings.json` 都跟着 exe 走。

## 写作小技巧

- 数字写得大一些、笔画粗一些, 并与 MNIST 风格一致(白底黑字自动反色)。
- 尽量写在画布中央, 虽然预处理会自动居中, 但不要超出画布边界。
- 自定义训练时, 每个类别最好有十几张以上样本, 并且**训练集和测试集都要有**,
  这样训练完能立刻用 `测试` 看到效果。
- 一个数据集的样本要"同类" —— 它的名字就是这一类别的标签。
